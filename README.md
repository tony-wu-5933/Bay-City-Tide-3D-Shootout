# 🏀 灣區浪潮 3D 街頭投籃（Bay City Tide 3D Streetball）
---

## 一、作品概念

一款在瀏覽器即可遊玩的 **3D 籃球小遊戲**。玩家操控穿著 **2026 藍色球衣的大頭（Q 版）球員**，在 **標準 NBA 半場** 上用 **WASD 自由跑位、運球**，用 **Crossover／胯下運球** 晃開 AI 防守者，再按 **空白鍵** 蓄力跳投。左側面板可設定球員、投籃動作、場地風格、防守者、遊戲模式與視角。

- 單一 `index.html`，HTML + CSS + JavaScript 全部寫在同一檔
- 3D 引擎：Three.js r128（CDN 載入）
- 所有貼圖（球衣號碼、球場線、觀眾席、霓虹招牌）皆用 Canvas 程式即時繪製，**不需要任何圖片檔**
- 音效以 Web Audio API 即時合成（運球、球鞋摩擦、刷網、打框、籃板、歡呼、跌倒、終場哨）

> 原始需求為「勇士隊球員」。考量真實球員肖像與球隊／聯盟商標的權利問題，與 AI 討論後改為 **原創虛構球隊「灣區浪潮 Bay City Tide」**，保留藍色球衣、金色號碼的灣區配色，所有球員皆為原創角色。

## 三、操作方式

| 按鍵 | 功能 |
|---|---|
| **W A S D**（或方向鍵） | 依畫面方向移動，移動時自動運球並播放跑步動畫 |
| **Shift** | 按住衝刺（速度 ×1.55，腳下揚起塵土） |
| **Q** | **Crossover**：球從身前低運換到另一手，並往新方向爆發加速 |
| **E** | **胯下運球**：壓低重心、雙腿張開，球從胯下穿過換手並向前推進 |
| **空白鍵** | 按住蓄力（球員自動轉身面向籃框）、放開跳投 |
| **F** | 發動招牌動作（能量滿時） |
| **C** | 切換視角 |
| **R** | 回到罰球線 |

- **滑鼠只用來操作左側選單**，點擊畫面不會投籃，避免誤觸。
- 焦點停在按鈕或勾選框時按空白鍵，不會誤觸該按鈕，一律當作投籃。

## 四、球員系統

### 4.1 大頭球員造型
以 Three.js 幾何體組合：超大球形頭、大眼睛＋高光、眉毛、腮紅、微笑；藍色無袖球衣（正面 `TIDE` + 金色號碼、背面姓氏 + 號碼、金色 V 領與側邊條）、藍色球褲、金色護腕、白襪、彩色球鞋。每位球員有不同膚色與髮型。腿部以髖關節為軸，可做跑步擺腿、胯下張腿等動作。

### 4.2 球員名單與數值

| 球員 | 定位 | 三分 | 中距離 | 穩定度 | 力量 | 抗壓 | 速度 | 招牌動作 |
|---|---|---|---|---|---|---|---|---|
| #8 Ray Lin  | PG 神射手 | 97 | 90 | 93 | 76 | 95 | 85 | 浪花 Logo 三分 |
| #14 Marcus Hale | SG 後撤步大師 | 91 | 92 | 86 | 84 | 90 | 88 | 雙重後撤步 |
| #21 Theo Brooks | SF 中距離殺手 | 83 | 97 | 89 | 92 | 91 | 80 | 金門後仰 |
| #3 Kenji Mori  | PG 速度型控衛 | 89 | 86 | 90 | 80 | 86 | 96 | 旋風急停跳投 |

### 4.3 數值如何影響遊戲
| 數值 | 效果 |
|---|---|
| 三分 / 中距離 | 依出手位置決定完美區大小 |
| 穩定度 | 降低出手左右偏差 |
| 力量 | 遠距離時完美區縮小得比較少 |
| 抗壓 | 60 秒挑戰最後 15 秒的完美區加成 |
| 速度 | 移動速度（2.6 + 速度×1.5 m/s），也提高晃倒防守者的機率 |

### 4.4 選角過程
點選球員卡 → 金框高亮 → 6 項數值條與 OVR 動畫增長 → 顯示招牌動作說明 → 3D 鏡頭切到球員正面特寫，球員舉手歡呼並說出台詞（Let's go!）。

### 4.5 招牌動作（F 鍵）
| 招牌 | 動畫 | 特效／台詞 |
|---|---|---|
| 浪花 Logo 三分 | 超高弧度出手（+7°） | 命中炸出藍色浪花；「Splash Logo!」 |
| 雙重後撤步 | 連續兩段後撤 1.3 公尺 | 金色殘影；「Step back... BANG!」 |
| 金後仰 | 大角度後仰並後退 | 金色光點殘影；「Golden Gate!」 |
| 旋風急停跳投 | 原地 360° 轉身出手 | 綠色旋風粒子；「Cyclone!」 |

命中累積能量（一般 +25%、空心 +35%、晃倒對手 +20%），集滿後按 F：下一球完美區 ×2.2～2.4、**得分 ×2**。

## 五、運球系統

| 項目 | 規格 |
|---|---|
| 一般運球 | 球在慣用手側彈地，跑得越快運球頻率越高、球越往前；另一手護球 |
| Crossover（Q） | 0.42 秒，球從身前 V 字低運換手，往新手方向側向爆發 3.0 m/s |
| 胯下運球（E） | 0.5 秒，蹲低 0.24m、雙腿張開，球穿過胯下換手，向前推進 2.0 m/s |
| 連續招式 | 1.3 秒內接第二個招式顯示「COMBO ×2」，晃倒機率 +28% |
| 投籃後 | 球自動回傳到球員手上繼續運球（拋物線回傳動畫） |

## 六、AI 防守者

| 項目 | 規格 |
|---|---|
| 開關 | 左側「④ 防守者」勾選加入，可選簡單／普通／困難 |
| 造型 | 原創白紅客隊球衣 #0 Max Rowe、皺眉表情 |
| 站位 | 站在球員與籃框連線上；三分線外遠處會放空（距離 1.5～2.3m），進入射程後貼身（1.15m） |
| 移動 | 防守滑步、最高速 2.3／3.1／3.9 m/s（依難度），會跟球員碰撞推擠 |
| 干擾 | 球員蓄力時貼近到 0.95m 並高舉雙手，出手時起跳封蓋 |
| 晃倒 | 在 2.1m 內做招式時判定，基礎機率 Crossover 42%、胯下 36%，加上連招、速度數值、難度修正；成功時防守者向後跌坐約 2.6 秒 |

### 出手品質
| 品質 | 條件 | 完美區 | 左右偏差 |
|---|---|---|---|
| 晃倒 WIDE OPEN | 防守者跌倒中 | ×1.25 | ×0.8 |
| 空檔 OPEN | 無防守或距離 > 2.1m | ×1.1 | ×1.0 |
| 有干擾 CONTESTED | 防守者在前方 1.25～2.1m | ×0.75 | ×1.3 |
| 嚴密防守 LOCKED | 防守者在前方 < 1.25m | ×0.5 | ×1.7 |

後撤步、後仰跳投可把防守干擾降一級。

## 九、投籃與計分

### 9.1 投籃動作（左側選單）
| 動作 | 完美區 | 左右偏差 | 位移 | 特點 |
|---|---|---|---|---|
|  標準跳投 | ×1.00 | ×1.00 | — | 最穩定 |
|  急停跳投 | ×0.93 | ×1.05 | 前進 0.35m | |
|  後撤步跳投 | ×0.85 | ×1.15 | 後退 0.75m | 防守干擾降一級 |
|  後仰跳投 | ×0.80 | ×1.12 | 後退 0.35m＋後仰 | 防守干擾降一級 |

### 9.2 力道判定與物理
- 指針在力道條上下來回，距離越遠越快；綠色完美區大小會隨防守者距離**即時變化**
- 完美區放開：力道誤差 ±0.6%、左右偏差減半；偏離則誤差 1.3% 起跳
- 拋物線初速公式（出手角 46°～53°，籃下 2.2m 內改 60° 拋投），重力 9.81 m/s²，每幀 8 個子步驟
- 籃框環狀碰撞、籃板碰撞、地板彈跳；球心由上往下穿過籃框平面判定進球

### 9.3 計分
| 項目 | 分數 |
|---|---|
| 三分線內／外（依起跳位置判斷，含底角） | 2 ／ 3 |
| 空心 SWISH | +1 |
| Logo 超遠（距籃框 > 10m） | +1 |
| ON FIRE（連進 3 球起） | +1 |
| 熱區（60 秒挑戰） | +2 |
| 招牌動作 | 總分 ×2 |

### 9.4 遊戲模式
| 模式 | 規則 | 結算 |
|---|---|---|
| 自由練習 | 不限時間，自由跑位投籃 | — |
| 60 秒熱區挑戰 | 場上有紅色發光熱區，在圈內投進 +2，熱區會換位置 | 評等 S/A/B/C，最佳紀錄存在瀏覽器 |
| 環場挑戰 | 走進金色發光圈內投進才能前進，共 7 站 | 依出手數評等 |

### 9.5 視角
跟隨視角（預設，方向固定、WASD 最直覺）、面向籃框視角、側邊轉播、高空俯瞰。WASD 永遠依「目前鏡頭方向」移動。

## 十、與 AI 反覆調整紀錄（Vibe Coding 過程）

| 回合 | 問題／想法 | 調整結果 |
|---|---|---|
| 1 | 提出需求：勇士球員、大頭、左側設定、三種場地、標準半場 | AI 提醒不能使用真實球員肖像與商標，改為原創球隊「灣區浪潮」並保留藍色球衣 |
| 2 | 規格細化 | 加入球員數值與實際影響、招牌動作、4 種投籃動作、3 種模式、多種視角 |
| 3 | 第一版完成並實測 | 5 個代表位置完美出手全部命中，計分正確 |
| 4 | 職業場館地板過曝成淡青色 | 調降聚光燈與環境光強度、提高地板粗糙度 |
| 5 | LED 跑馬燈文字重疊、被切斷 | 用 `measureText` 排版、縮小字級、重複次數取整數 |
| 6 | 地上出現像海星的怪陰影 | 關閉棕櫚葉投影 |
| 7 | 招牌殘影粒子是方塊 | 改用放射漸層圓形貼圖 |
| 8 | 側邊視角球員被擠在邊緣 | 鏡頭拉遠並偏移 |
| 9 | **第二版需求**：不要定點投籃，要 WASD 移動、運球（Crossover／胯下）、進球說 Nice shot、改空白鍵投籃避免滑鼠誤觸 | AI 先反問三件事：要不要防守者、台詞用語音還是文字、招式按鍵配置。決定：**防守者可開關**、**文字對話泡泡**、**Q／E／Shift** |
| 10 | 實作第二版 | 新增移動系統、腿部關節跑步動畫、運球物理路徑、Crossover／胯下動畫、AI 防守者與晃倒判定、出手品質、對話泡泡、熱區／環場發光圈、手機虛擬搖桿；滑鼠不再觸發投籃 |
| 11 | 第二版實測 | W 往籃框前進、A＋Shift 衝刺、Q／E 正確換手；連續招式成功晃倒防守者，晃倒後空檔出手命中，畫面顯示 Get up! / Whoa!! 泡泡 |
